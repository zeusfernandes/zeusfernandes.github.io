# Zeus Fernandes — Interactive Portfolio

A responsive static portfolio for GitHub Pages. Includes a light theme, profile photo, career timeline, filterable project cards, skill cards, graduating project, music sidebar, copy-email button and subtle scroll animations.

## Publish
1. Create/open the public repository `zeusfernandes.github.io`.
2. Upload the **contents** of this folder to the repository root (including `script.js`, `style.css`, the photo and PDF).
3. In Settings → Pages, choose Deploy from a branch → main → /(root).
4. Visit https://zeusfernandes.github.io after deployment.

## Privacy
The website and linked PDF are public. Review contact information before publishing. Work project cards describe responsibilities without exposing internal code or datasets.
