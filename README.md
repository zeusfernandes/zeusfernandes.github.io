# Zeus Fernandes — GitHub Pages portfolio

A responsive static portfolio website based on the attached CV. No build tools or dependencies needed.

## Publish at zeusfernandes.github.io

1. Sign in to GitHub as `zeusfernandes`.
2. Create a **public** repository named **`zeusfernandes.github.io`**.
3. Upload the files in this folder **to the repository root** (not inside a nested folder).
4. Open repository **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
5. After deployment, visit **https://zeusfernandes.github.io/**.

To update the site, edit `index.html` or `style.css`, and commit the changes. Replace the PDF when your CV changes.
